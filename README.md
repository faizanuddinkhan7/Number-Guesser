## 📖 Overview
Created to cure boredom, has 10 attempts and is extremely fast and lightweight

---

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/faizanuddinkhan7/Number-Guesser.git
cd Number-Guesser
```

---

## 🚀 Compile and Execute the Program
Compile
```bash
# Compile the program with gcc
gcc main.c -o main
```

Run
```bash
# Execute the program
./main
```
